# 🏠 Our Homie

> *"Manage our home together. Shopping, calendar, pets, and shared finances, all in one app."*

A warm, mobile-first couple & household companion web application built with **React**, **Vite**, and **Tailwind CSS**.

---

## ✨ Features

- 🔐 **Dual-Partner Space**: Seamless 1-tap perspective switcher between partners (Cartune 👩🏻 & Gun 👦🏻).
- 🛒 **Shared Shopping List**: Real-time category filtering, inline item additions, strike-through checkbox, and badge counters.
- 📅 **Couple Calendar & Mood Heatmap**:
  - **Events vs Tasks**: Distinct tags and interactive completion checkboxes.
  - **Time Picker**: Precise hour & minute scheduling with quick presets (`09:00`, `14:30`, etc.).
  - **Dual-Partner Mood Tracker**: 2-color diagonal split cells on calendar, mood check-ins, and couple insight summaries.
- 🐾 **Comprehensive Pet Care**:
  - Full CRUD (Edit details, add pets with preset photos, delete records).
  - Schedule vet & vaccine appointments straight into the shared Calendar.
  - Quick routine completion rewarding +15 household award points.
- 💰 **Shared Finances & Expense Splitter**:
  - Track total monthly spending and partner split bars (`Cartune Paid` vs `Gun Paid`).
  - Automatic 50/50 balance settlement calculation ("Who owes whom").
  - Category budget progress bars with over-budget alerts.
  - Instant rollback math when deleting transactions.
- 👤 **Customizable Profile & Couple Goals**:
  - Change display names, roles (แฟน, ที่รัก, ภรรยา, สามี), 24 emoji avatars, and 8 accent color themes.
  - Set mutual rewards (*"ย้อมผมที่ enrich"*, *"ทริปญี่ปุ่น"*), target points, and award surprise bonus points.
- ☁️ **GitHub Cloud Data Vault (Aura-style sync)**:
  - Zero-cost cross-device synchronization using GitHub REST API.
  - Automatic conflict-free union merge with local-only token security.

## 🚀 Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Run locally
```bash
npm run dev
```

### 3. Build for production
```bash
npm run build
```

---

## 🌐 Deploy to Vercel

1. Push this repository to GitHub (`primoinf/our-homie-app`).
2. Log in to [Vercel](https://vercel.com) and click **"Add New Project"**.
3. Import `our-homie-app`.
4. Click **Deploy**!
